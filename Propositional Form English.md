## Examples

Given the atoms:
$$
\begin{aligned}
\mathtt{P}\;:=\;& \text{The sine function is not one-to-one}.\\[12pt]
\mathtt{Q}\;:=\;& \text{The square root function is one-to-one}.\\[12pt]
\mathtt{R}\;:=\;& \text{The absolute value function is not onto}.
\end{aligned}
$$

Translate the following propositional forms:

### Example 1

$$
\begin{aligned}
\mathtt{(1)}\quad & \mathtt{P}\land \mathtt{Q}\lor \mathtt{R}\\[12pt]
& \mathtt{P}\land \mathtt{Q}\lor \mathtt{R}\ \text{reads as}\ \bigl(\mathtt{P}\land \mathtt{Q}\bigr)\lor \mathtt{R}.\\[12pt]
& \bigl(\mathtt{P}\land \mathtt{Q}\bigr)\lor \mathtt{R}\ \text{reads:}\\[12pt]
& \text{Either the sine function is not one-to-one and the square root function is one-to-one,}\\
& \text{or the absolute value function is not onto}.
\end{aligned}
$$

### Example 2

$$
\begin{aligned}
\mathtt{(2)}\quad & \mathtt{P}\land \bigl(\mathtt{Q}\lor \mathtt{R}\bigr)\\[12pt]
& \mathtt{P}\land \bigl(\mathtt{Q}\lor \mathtt{R}\bigr)\ \text{reads:}\\[12pt]
& \text{The sine function is not one-to-one and either the square root function is one-to-one}\\
& \text{or the absolute value function is not onto}.
\end{aligned}
$$
