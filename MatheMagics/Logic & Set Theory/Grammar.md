## Definition:
Finite, recursive rules ([[Propositional form or ((wffs) or (PL-formula))|propositional form]]) for combining symbols into valid expressions.  
It tells us which **strings** over an alphabet count **well-formed formulas** and which ones are not.
Determines which strings are legal.
