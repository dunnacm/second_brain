## Examples:

Given the atoms:
$$
\begin{aligned}
\mathtt{P}\;:=\;& \text{The sine function is not one-to-one}.\\[12pt]
\mathtt{Q}\;:=\;& \text{The square root function is one-to-one}.\\[12pt]
\mathtt{R}\;:=\;& \text{The absolute value function is not onto}.
\end{aligned}
$$

Translate the following propositional forms:

### Example 1: $\mathtt{P}\land \mathtt{Q}\lor \mathtt{R}$

$$
\begin{aligned}
& \mathtt{P}\land \mathtt{Q}\lor \mathtt{R}  = \bigl(\mathtt{P}\land \mathtt{Q}\bigr)\lor \mathtt{R}\ \text{reads:}
\end{aligned}
$$
*Either* the sine function is not one-to-one and the square root function is one-to-one, *or* the absolute value function is not onto
### Example 2: $\mathtt{P}\land \bigl(\mathtt{Q}\lor \mathtt{R}\bigr)$

$$
\begin{aligned}
& \mathtt{P}\land \bigl(\mathtt{Q}\lor \mathtt{R}\bigr)\ \text{reads:}
\end{aligned}
$$
The sine function is not one-to-one and *either* the square root function is one-to-one *or* the absolute value function is not onto.
### Example 3: $\neg\bigl(\mathtt{P}\land \mathtt{Q}\bigr)$

$$
\begin{aligned}
& \neg\bigl(\mathtt{P}\land \mathtt{Q}\bigr)\ \text{reads:}
\end{aligned}
$$

- It is not the case that both the sine function is not one-to-one and the square root function is one-to-one.
OR
- It is false that the sine function is not one-to-one and the square root function is one-to-one.

### Example 4: $\neg \mathtt{P}\land \mathtt{Q}$

$$
\begin{aligned}
& \neg \mathtt{P}\land \mathtt{Q}\ \text{reads:}
\end{aligned}
$$

The sine function is one-to-one and the square root function is one-to-one.

### Example 5: $\neg \mathtt{P}\land \neg \mathtt{Q}$

$$
\begin{aligned}
& \neg \mathtt{P}\land \neg \mathtt{Q}\ \text{reads:}
\end{aligned}
$$

*Neither* does the sine function is one-to-one *nor* the square root function is not one-to-one.

### Example 6: $\mathtt{Q}\leftrightarrow\neg\mathtt{R}$

$$
\begin{aligned}
& \mathtt{Q}\leftrightarrow\neg\mathtt{R}\ \text{reads:}
\end{aligned}
$$

The square root function is one-to-one if and only if the absolute value function is onto.

### Example 7: $\mathtt{R}\to\mathtt{Q}$

$$
\begin{aligned}
& \mathtt{R}\to\mathtt{Q}\ \text{reads:}
\end{aligned}
$$

If the absolute value function is not onto, then the square root function is one-to-one.

### Example 8: $\mathtt{P}\lor\mathtt{R}\to\neg\mathtt{Q}$

$$
\begin{aligned}
& \mathtt{P}\lor\mathtt{R}\to\neg\mathtt{Q}
= (\mathtt{P}\lor\mathtt{R})\to\neg\mathtt{Q}\ \text{reads:}
\end{aligned}
$$

If either the sine function is not one-to-one or the absolute value function is not onto, then the square root function is not one-to-one.

### Example 9: $\mathtt{Q}\leftrightarrow\mathtt{R}\land\neg\mathtt{Q}$

$$
\begin{aligned}
& \mathtt{Q}\leftrightarrow\mathtt{R}\land\neg\mathtt{Q}
= \mathtt{Q}\leftrightarrow(\mathtt{R}\land\neg\mathtt{Q})\ \text{reads:}
\end{aligned}
$$

The square root function is one-to-one iff (if and only if) both the absolute value function is not onto and the square root function is not one-to-one.

### Example 10: $\mathtt{P}\lor\mathtt{Q}\land\mathtt{R}$

$$
\begin{aligned}
& \mathtt{P}\lor\mathtt{Q}\land\mathtt{R}
= \mathtt{P}\lor(\mathtt{Q}\land\mathtt{R})\ \text{reads:}
\end{aligned}
$$

Either the sine function is not one-to-one, or both the square root function is one-to-one and the absolute value function is not onto.

### Example 11: $(\mathtt{P}\lor\mathtt{Q})\land\mathtt{R}$

$$
\begin{aligned}
& (\mathtt{P}\lor\mathtt{Q})\land\mathtt{R}\ \text{reads:}
\end{aligned}
$$

The absolute value function is not onto, and either the sine function is not one-to-one or the square root function is one-to-one.
