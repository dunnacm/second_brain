## Definition:

**Propositional logic** was developed to model basic proof and truth. 
It was done by using propositional forms to represent sentences that were either true or false. 
It was proven that propositional logic is **consistent**, **sound**, and **complete**, however, the sentences of mathematics involve ideas that cannot be fully represented in propositional logic. 

These sentences are able to:
- Define **Objects** (subjects), e.g.,*numbers* or *geometric* figures
- by describing their **properties** (predicates), e.g., *even* or *rectangle*, 
- and the **relationship** between them e.g.,*equality* or *congruence*.

Since propositional logic is not well suited to handle these ideas, propositional logic is extended to a richer system: First-order logic (FOL)
