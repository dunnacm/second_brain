## Introduction:
### Illustration:
Consider the sentence "*it is a real number*". This sentence has no truth value because the meaning of the word *it* is undetermined. Let us make some **substitutions** for it:

![[Pasted image 20250905212902.png|300]]

Two insights to take from the example:

- There are two part of the sentence which serve different purposes: The first part is a reference to an **object**, and the second is a **property** of the object.

- Notice that the "*it*" part changes, whereas "*is a real number*" remains fixed.  In the example, one chooses a property and then test whether various objects have that property. **Substituting** only for the *subject* is a restriction that one makes in mathematics.
