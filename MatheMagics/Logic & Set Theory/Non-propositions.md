If a sentence asserts or denies accurately, the sentence is **true**.
If a sentence asserts or denies inaccurately, the sentence is **false**.
As arguments intend to draw conclusions (from presumably true premises), one limits the sentences to only those with a truth value. Those without a truth value lie outside of the study of logic
