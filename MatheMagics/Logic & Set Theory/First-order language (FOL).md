## **Alphabet** includes:
- **Logical symbols:** $¬, ∧, ∨, →, ↔, ∀, ∃, =, x_0, x_1, \dots$ 
- **Theory symbols:**  
	- Constants   
	- Function symbols  
	- Relation symbols
## **Restrictions**: 
Quantifiers (∀,∃) only *apply to individual objects* in the domain
## Examples:
- ∀x(P(x)→Q(x)) → “For every object x, if x has property P, then x has property Q.”
	- Here, x ranges over elements of the domain (say numbers, people, sets).
