## Fundamentals:

Distinguished **wff(s)** taken as starting truths.  
Require no proof or prior justification.  
Playing the same role as that of **postulates** in Euclidean geometry.  
The number of axioms should be as few as possible as to minimize the number of assumptions
An axiom can be considered as "rules of the game".
### Example:

Depending on its axioms, geometry can be:
- No parallel lines: Spherical geometry
- One parallel line: Plane (Euclidean) geometry
- More than one parallel line: Hyperbolic geometry
