## Definition:

The predicate of a sentence is the expression that ascribes a property to the object identified by the subject (the variables of the sentence)

## Categorized by:

### Number of variables:

- #### Single variable: 
	The predicate x + 2 = 7, has *x* as it's only variable
- #### Multiple variables:
	The predicate x + 2 = 7 where *x* is *substituted* by (x =) $y + 2z^2$, yields a predicate with multiple variables (x =) $y + 2z^2 +2 = 7$
### Number of occurrences:

Let the predicate be x + 2 = 7. If one substitutes $x = y^2 - 7 \cdot y$, the result is predicate with multiple occurrences of the same variable: $y^2-7y+2=7$.
