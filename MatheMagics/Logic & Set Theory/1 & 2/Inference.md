## Inference rules:
Inference rules for both **propositional logic** and **propositions derived from first-order sentences**:
- Modus Ponens
- Modus Tollens
- Constructive Dilemma 
- Destructive Dilemma
- Hypothetical Syllogism 
- Conjunction
- Simplification
- Addition
- Direct (conditional) proof (DP)
- Indirect proof
- Universal instantiation (UI)
- Universal generalization (UG)
