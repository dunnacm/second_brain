## Definition:

A formula of the form ∃x φ(x) is an **existential proposition**.
It claims the existence of at least one object from the *domain* that makes the predicate φ(x) true.

![[Pasted image 20250906134118.png|500]]
### Example:

| VERBALIZATIONS                                           | SET THEORY                                        |
| -------------------------------------------------------- | ------------------------------------------------- |
| ***There exists*** *a real number x such that x + 2 = 7* | $(\exists x \in \mathbb{R}) \; [\, x + 2 = 7 \,]$ |
| ***Some*** real number *x satisfies x + 2 = 7*           | (*same as first*)                                 |
| *x + 2 = 7 for some real number x*                       | $x + 2 = 7, \;\; \exists x \in \mathbb{R}$        |
