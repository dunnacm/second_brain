> [!note]+ **Extending a Theory-Symbol Set**
>
> > [!warning]+ **IF**
> > - $A$ is a first-order alphabet.
> > - $S\subseteq A$ ($S$ is the set of theory symbols in $A$).
> > - $C=\{\,c_i \mid i\in I\,\}$ is a set of **new theory symbols** (typically new constant symbols)
> > - $C\subseteq A\setminus S.$
> > - (Optional but standard) $C\cap S=\varnothing$.
>
> > [!tip]+ **THEN**
> > $$\overline{S}=S\cup C.$$
