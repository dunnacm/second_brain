## Building a theory

A (formal) **mathematical theory** is specified by:

1) choosing a first-order **alphabet/language** (i.e., choosing the **theory symbols** $S$ you want to talk about—constants, function symbols, predicate symbols—together with the fixed logical symbols), and then

2) choosing a set of **axioms**: sentences (closed formulas) written in that language.

So, informally:

> **Theory = (language / theory symbols $S$) + (axioms in that language).**

*(The set of theory symbols may be empty; then the only available symbols are the logical ones.)*
