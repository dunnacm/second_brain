> [!note] **Definition 2.3.6 — Particular constant symbol (witness)**
>
> > [!warning] **IF**
> > - A constant first appears 
> > > - **not** by UI (e.g., as a Given/Add), **or** 
> > > - it is introduced by **EI** ($\exists x\, p(x) \Rightarrow p(\hat a)$) with a **fresh** constant.
>
> > [!tip] **THEN**
> > - It is a **particular** constant symbol (often written $\hat a$).


>[!warning] **Restriction**:
> **UG** ***cannot*** be applied to formulas that contain particular constants.
