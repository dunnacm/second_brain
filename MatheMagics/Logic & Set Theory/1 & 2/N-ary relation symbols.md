## Definition:

An **n-ary relation symbol** (*R*) is a *theory symbol* in FOL that denotes a relation among *n* objects of the domain. 
When applied to *n* terms, it forms an *atomic formula* that is either true or false in a given theory, interpretation or model. 

## Examples:

- **Unary relation symbol** P(x): "*x* is prime"
- **Binary relation symbol** < (x,y): "*x* is less than *y*"
- **Ternary relation symbol** Between(x,y,z): "*y* is between *x* and *z*"
