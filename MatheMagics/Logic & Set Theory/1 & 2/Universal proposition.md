## Definition:
A formula of the form ∀x φ(x) is an **universal proposition**.
It claims that no matter which object one chooses from the *domain*, the predicate φ(x) will always be true.

![[Pasted image 20250906134242.png|500]]

### Example:

| Verbalization                                    | Set theory                                            |
| ------------------------------------------------ | ----------------------------------------------------- |
| ***For all*** *real numbers x, x + 5 = 5 + x*    | $(\forall x \in \mathbb{R}) \; [\, x + 5 = 5 + x \,]$ |
| *x + 5 = 5 + x*  ***for every*** *real number x* | $x + 5 = 5 + x, \;\; \forall x \in \mathbb{R}$        |
