## Definition
An argument = **(** Premise(s) ) + ( Conclusion(s) **)**
It is organized so that the conclusion is claimed to follow from the premises.
### Example:
**PREMISE 1**: If squares are rectangles, then squares are quadrilaterals.
**PREMISE 2**: Squares are rectangles.
**CONCLUSION**: Squares are quadrilaterals
