## Definition
A **wff** is a finite *string* of symbols from the *alphabet* of a logical system that is generated by the *grammar* rules of that system

### Preliminaries
 **propositional form** (a **PL-formula**) is a **well-formed formula** (**wff**) built from the symbols of the **propositional alphabet**:

#### Alphabet (object language)
- **Propositional variables:** $P,Q,R,\dots$ and $P_n,Q_n,R_n,\dots$
- **Logical connectives:** $\lnot,\ \land,\ \lor,\ \to,\ \leftrightarrow$
- **Grouping symbols:** $(\ )$ and $[\ ]$

#### Metavariables / notation conventions (metalanguage)
Metavariables: 
- $\mathtt{p,q,r,\dots,} \varphi,\psi$ stand for a finite sequence of characters (string) from a given collection of symbols (alphabet); they stand for arbitrary propositional forms.
- $\Gamma$ is **metavariable** for a set (or sequence) of propositional forms
- Metavariables are not part of the proposition alphabet

### Recursive definition
1. Every propositional variable is a propositional form.  
2. If $\varphi$ and $\psi$ are propositional forms, then so are:  
	 - $\lnot \varphi$  
	 - $(\varphi \land \psi)$  
	 - $(\varphi \lor \psi)$  
	 - $(\varphi \to \psi)$  
	 - $(\varphi \leftrightarrow \psi)$  
3. Nothing else counts as a propositional form.

## Syntactic character
A **wff** (well-formed formula) is a **purely syntactic** object: a string built according to the formation rules of the language.  
It is “legal” **regardless of meaning**.

## Semantics
A wff does not come with a truth value by itself. Truth (or satisfaction) is defined only **relative to semantic data**.

- **In propositional logic (PL):**
	- A valuation/assignment $v:\mathtt{Var}\to\{\mathtt{T},\mathtt{F}\}$ assigns truth values to propositional variables and extends to all wffs.  
	- Relative to $v$, a propositional wff has a **truth value** (equivalently, it determines a truth-function / proposition-as-truth-condition).

- **In first-order logic (FOL):**
	- One needs a **structure** (domain + meanings for nonlogical symbols) and a **variable assignment** (values for variables), which together determine the denotation of terms and the satisfaction of formulas.
	- If $\varphi$ has **free variables**, it is an **open formula**; its truth is evaluated *under an assignment* (so it behaves like a predicate on the domain, relative to the structure).
	- If $\varphi$ has **no free variables** (a **sentence**), its truth in the structure is **assignment-independent** (it is simply true or false in that structure).

## Rationale
Only **wffs** count as propositional forms.

A propositional form, by itself, does not determine a truth value until we choose a **valuation**
$$
\upnu:\mathtt{PropVar}\to\{\top,\bot\},
$$
since its truth depends on the truth values assigned to its propositional variables.

Informally: a propositional form is an abstract pattern of logical structure, and it becomes truth-valued only relative to an assignment of truth values to its variables.

### Example #1
Proposition: “If squares are rectangles, then squares are quadrilaterals.”  
Propositional form: $p\to q$. [^1]

### Example #2 (not a propositional form)
$x+2=5$ is **not** a propositional form (it is not a formula of propositional logic).  
It becomes truth-valued only after we interpret it in a different logical setting (e.g., arithmetic with an assignment to $x$).

## Types
Types of propositional forms:
- atomic propositional forms (propositional variables)
- compound propositional forms

---
[^1]: The same form $p\to q$ could represent “If it rains, then the ground is wet,” or countless other sentences. This illustrates the role of assigning truth values (via $\upnu$) or interpreting the variables informally.
