| 1   | symmetry                   | $\lvert a\rvert=\lvert -a\rvert$.                                       |

| 3   | zero characterization      | $\lvert a\rvert=0\ \Leftrightarrow\ a=0$.                               |
| 4   | idempotence                | $\lvert\,\lvert a\rvert\,\rvert=\lvert a\rvert$.                        |

| 9   | zero distance              | $\lvert a-b\rvert=0\ \Leftrightarrow\ a=b$.                             |
