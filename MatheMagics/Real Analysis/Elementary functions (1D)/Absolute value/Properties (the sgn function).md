| #   | Name/Theme                        | Property                                                                                                                                                                                                                                 |
| --- | --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | symmetry                          | $\operatorname{sgn}(-x) = -\,\operatorname{sgn}(x)$.                                                                                                                                                                                     |
| 2   | zero characterization             | $\operatorname{sgn}(x)=0 \quad \Leftrightarrow \quad x=0$.                                                                                                                                                                               |
| 3   | relation with absolute value      | $x = \operatorname{sgn}(x)\,\lvert x\rvert$.                                                                                                                                                                                             |
| 4   | power identity                    | $$<br>\operatorname{sgn}(x)^n =<br>\begin{cases}<br>\operatorname{sgn}(x), & \text{if } n \text{ is odd},\\<br>0, & \text{if } n \text{ is even and } x=0,\\<br>1, & \text{if } n \text{ is even and } x\neq 0.<br>\end{cases}<br>$$<br> |
| 5   | product decomposition             | $\operatorname{sgn}(xy) = \operatorname{sgn}(x)\,\operatorname{sgn}(y)$.                                                                                                                                                                 |
| 6   | quotient decomposition            | **If** $\begin{aligned}&y\ne 0\end{aligned}$ **then** $\operatorname{sgn}\!\left(\dfrac{x}{y}\right) = \operatorname{sgn}(x)\,\operatorname{sgn}(y)$.                                                                                    |
| 7   | relation with absolute difference | $\operatorname{sgn}(x-y) = \begin{cases} -1 & x<y, \\ 0 & x=y, \\ 1 & x>y. \end{cases}$                                                                                                                                                  |
