## 1. arithmetic mean (definition)

Let $a,b\in\mathbb{R}$. The arithmetic mean is $m=\dfrac{a+b}{2}$.

## 2. midpoint symmetry

With $m=\dfrac{a+b}{2}$, we have $a-m=m-b$.

## 3. band via distance to the mean (non-strict)

### 3.1

$a\le x\le b \ \Leftrightarrow\ \lvert x-m\rvert \le b-m=\dfrac{b-a}{2}$.

### 3.2

$a\le x\le b \ \Leftrightarrow\ \left\lvert x-\dfrac{a+b}{2}\right\rvert \le b-\dfrac{a+b}{2}=\dfrac{b-a}{2}$.

### 3.3

$a\le x\le b \ \Leftrightarrow\ \lvert\,2x-(a+b)\rvert \le b-a$.

## 4. band via distance to the mean (strict)

### 4.1

$a<x<b \ \Leftrightarrow\ \lvert x-m\rvert < b-m=\dfrac{b-a}{2}$.

### 4.2

$a<x<b \ \Leftrightarrow\ \lvert\,2x-(a+b)\rvert < b-a$.

## 5. reverse band (non-strict)

### 5.1

$a\ge x\ge b \ \Leftrightarrow\ \lvert x-m\rvert \le a-m=\dfrac{a-b}{2}$.

### 5.2

$a\ge x\ge b \ \Leftrightarrow\ \lvert\,a+b-2x\rvert \le a-b$.

## 6. reverse band (strict)

### 6.1

$a>x>b \ \Leftrightarrow\ \lvert x-m\rvert < a-m=\dfrac{a-b}{2}$.

### 6.2

$a>x>b \ \Leftrightarrow\ \lvert\,a+b-2x\rvert < a-b$.
