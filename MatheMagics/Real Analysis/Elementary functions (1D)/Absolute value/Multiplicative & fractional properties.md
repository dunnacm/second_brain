| # | Name/Theme                        | Property |
|---|-----------------------------------|----------|
| 1 | product                           | » **1.1** $\lvert ab\rvert=\lvert a\rvert\,\lvert b\rvert$. |
|   |                                   | » **1.2** $\lvert abc\rvert=\lvert a\rvert\,\lvert b\rvert\,\lvert c\rvert$. |
|   |                                   | » **1.3** $\lvert a_1\cdots a_n\rvert=\lvert a_1\rvert\cdots\lvert a_n\rvert$. |
| 2 | reciprocals & quotients           | » **2.1** **If** $\begin{aligned}&a\neq 0\end{aligned}$ **then** $\left\lvert\dfrac{1}{a}\right\rvert=\dfrac{1}{\lvert a\rvert}$. |
|   |                                   | » **2.2** **If** $\begin{aligned}&b\neq 0\end{aligned}$ **then** $\left\lvert\dfrac{a}{b}\right\rvert=\dfrac{\lvert a\rvert}{\lvert b\rvert}$. |
| 3 | scaling by modulus factor         | » **3.1** **If** $\begin{aligned}&\lvert b\rvert>1,\\&\lvert a\rvert>0\end{aligned}$ **then** $\lvert a\rvert<\lvert ab\rvert$. |
|   |                                   | » **3.2** **If** $\begin{aligned}&0<\lvert b\rvert<1,\\&\lvert a\rvert>0\end{aligned}$ **then** $\lvert ab\rvert<\lvert a\rvert$. |
|   |                                   | » **3.3** **If** $\begin{aligned}&\lvert b\rvert=1\end{aligned}$ **then** $\lvert ab\rvert=\lvert a\rvert$. |
|   |                                   | » **3.4** **If** $\begin{aligned}&\lvert a\rvert>1,\\&\lvert b\rvert>1\end{aligned}$ **then** $1<\lvert a\rvert<\lvert ab\rvert\ \text{ and }\ 1<\lvert b\rvert<\lvert ab\rvert$. |
|   |                                   | » **3.5** **If** $\begin{aligned}&\lvert ab\rvert\ne\lvert a\rvert\end{aligned}$ **then** $\lvert b\rvert\ne 1$. |
| 4 | discrete scaling (nonzero integers) | » **4.1** **If** $\begin{aligned}&a,b\in \mathbb{Z}\setminus\{0\},\\&\lvert a\rvert\ne 1,\\&\lvert a\rvert\ne \lvert ab\rvert\end{aligned}$ **then** $1<\lvert a\rvert<\lvert ab\rvert$. |
|   |                                   | » **4.2** **If** $\begin{aligned}&a,b\in \mathbb{Z}\setminus\{0\},\\&\lvert a\rvert\ne 1,\\&\lvert b\rvert\ne 1\end{aligned}$ **then** $1<\lvert a\rvert<\lvert ab\rvert$. |
|   |                                   | » **4.3** **If** $\begin{aligned}&a,b\in \mathbb{Z}\setminus\{0\},\\&\lvert a\rvert\ne \lvert ab\rvert,\\&\lvert b\rvert\ne \lvert ab\rvert\end{aligned}$ **then** $1<\lvert a\rvert<\lvert ab\rvert$. |
