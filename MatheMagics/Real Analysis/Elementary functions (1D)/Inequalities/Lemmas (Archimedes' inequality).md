| 1  | two-sided quadratic squeeze      | If $\begin{aligned}&n\in\mathbb{N},\\&n\ge 1\end{aligned}$ then $(n-1)(2n-1) < 2n^{2} < (n+1)(2n+1)$. |
| 2  | upper bound (corollary)          | If $\begin{aligned}&n\in\mathbb{N},\\&n\ge 1\end{aligned}$ then $(n+1)(2n+1) > 2n^{2}$. |
