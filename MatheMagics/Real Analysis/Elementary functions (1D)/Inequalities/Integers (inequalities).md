## Properties I
Let $m,n \in \mathbb{Z}$

| #   | Name                                 | Property                                                                                                                                                                                                                                                                                               |
| --- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | integer “step” and sign equivalences | » **1.1** $\,n>0\;$ **iff** $\,n\ge 1$.<br>» **1.2** $\,n<0\;$ **iff** $\,n\le -1$.<br>» **1.3** $\,n>m\;$ **iff** $\,n\ge m+1$.<br>» **1.4** $\,n<m\;$ **iff** $\,n\le m-1$.<br>» **1.5** If $\,n<m\,$ then $\,n=m-1\,$ **or** $\,n<m-1$.                                                             |
| 2   | growth bounds for integers           | » **2.1** If $n>1$ then $n^{2}\ge 2n$.<br>» **2.2** If $n>1$ then $2n>n+1$.<br>» **2.3** If $n>1$ then $n^{2}>n+1$.<br>» **2.4** If $n>1$ then $n(n+1)>n+2$.<br>» **2.5** If $n\ge 3$ then $n^{3}>(n+1)^{2}$.                                                                                          |
| 3   | higher-degree / product dominance    | If $n\ge 3$ then $n^{3}>(n+1)^{2}$.                                                                                                                                                                                                                                                                    |
| 4   | negative-range product               | If $n<-2$ then $n(n-1)>6$.                                                                                                                                                                                                                                                                             |
| 5   | factorial/product chain              | » **5.1** If $n>3$ then $n(n-1)(n-2)(n-3)>n^{2}$.<br>» **5.2** If $n\ge 7$ then $n(n-5)>n$.<br>» **5.3** If $n\ge 6$ then $(n-1)(n-4)>n$.<br>» **5.4** If $n\ge 5$ then $(n-2)(n-3)>n$.<br>» **5.5** If $n\ge 6$ then $n(n-1)\cdots(n-5)>n^{3}$.<br>» **5.6** If $n\ge 7$ then $n!>n(n-1)\cdots(n-5)$. |
| 6   | factorial vs. powers                 | » **6.1** If $n\ge 6$ then $n!>n^{3}$. <br>» **6.2** If $n>3$ then $n!>n^{2}$.                                                                                                                                                                                                                         |
