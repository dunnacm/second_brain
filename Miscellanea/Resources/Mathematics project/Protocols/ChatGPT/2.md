## Core LaTeX rules

- **Display math:** always use `$$...$$` (never `\[...\]`).
- **Fractions:** use `\dfrac` (never `\tfrac`).
- **Exponential operator:** prefer `\exp(\cdot)` when writing it as an operator; otherwise use `e^{...}` with braces for grouping.
- Avoid wide lines: break long expressions across lines while preserving your visual indentation.

## Aligned-environment formatting (your “kaizen template”)

- Use `$$\begin{aligned} ... \end{aligned}$$`.
- **Equation labels:** label-first form  
    `(n)\quad & ...`  
    (not `& (n)\quad ...`).
- **Narrative lines:** unlabeled lines start with  
    `& \mathtt{...}`.
- **Continuation lines and aligned equals:** when a line is a true continuation, align `=` under the previous `=` using manual indentation, e.g.  
    `& \qquad\ \qquad\ \ = ...`.
- **Implication lines with comments:**  
    `& \Rightarrow (k)\quad ... \qquad (\mathtt{...})`.
## Indentation and nesting logic

- Indent only when the line is conceptually subordinate.
- **Nested implications:** if `\Rightarrow (8)` follows from `\Rightarrow (7)`, indent (8) one level deeper, e.g.  
    `& \qquad\ \Rightarrow (8)\quad ...`.
- **No gratuitous indentation:** do **not** indent a standalone conclusion line if it is not a continuation of the previous line.
- **“Main consequence” pattern (from the asinh proof):**
    - Keep the main consequence line `& \Rightarrow (3)\quad ...` at base level when it concludes the preceding chain.
    - Indent the dependent follow-up lines under it with `& \qquad\ \qquad ...`.
    - Keep the next nested implication (e.g. `\Rightarrow (4)`) at that same sub-block indentation.
    - Indent the final “substitution back / final statement” one level deeper to close the block.

## Vertical spacing conventions

- Avoid overly large spacers by default.
- Use:
    - `\\[12pt]` after narrative headers and between closely related lines,
    - `\\[18pt]` between main equation lines within a block,
    - `\\[22pt]` to separate major sections (e.g., before “Sub.” / transitions). 
- Avoid `\\[26pt]`+ unless the source image clearly demands it.


## Text styling inside proofs

- In aligned proofs, keep **equations in plain math**; reserve `\mathtt{...}` for **commentary/narrative** (and split around variables when needed, e.g. `\mathtt{Expressing\ }y\mathtt{\ in\ terms\ of\ }x...`).
- End results often use a bold conclusion line consistent with your style (e.g., `\boldsymbol{\therefore\ ...}`) when present in the source or when you request it.

    - direct: `${\mathtt{fname}}(x)$`
    - inverse: `${\mathtt{fname}}^{-1}(x)$`
- Example you prefer: `{\mathtt{csch}}^{-1}(x)` rather than `\csch^{-1}(x)`.
