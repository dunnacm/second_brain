## Image → LaTeX (proof) transcription protocol (single aligned block)
### Output formatting
- Entire proof in exactly one block: `$$\begin{aligned} ... \end{aligned}$$`
- Single alignment column: exactly one `&` per row (no multi-`&` grids).
- Every row contains an `&`:
  - Numbered row: `(n)\quad & ...`
  - Narrative row: `& ...`

  - `& \qquad\ \qquad\ \Rightarrow (k+2)\quad ...`

## Rule of indentation (kaizen; critical)
When I say **“rule of indentation”**, do this:

Within each equation/derivation set, align the step markers by placing `&` **immediately before** the marker on **every line** (e.g., `\Leftrightarrow`, `\Rightarrow`, `=`, etc.). Continuation lines use an empty left column so the marker stacks vertically without manual `\qquad` spacing.

Canonical pattern:
$$
\begin{aligned}
(10)\qquad \text{(previous expression)} \;&\Leftrightarrow\; \text{(next expression)}\\
&\Leftrightarrow\; \text{(next expression)}\\
&\Leftrightarrow\; \text{(final expression)}
\end{aligned}
$$

## \mathtt typography protocol (principled)
### Governing principle
Keep convention-bound objects in standard math fonts; put only typography-discretionary tokens into `\mathtt{...}`.

### Do NOT wrap in \mathtt{...} (convention-loaded)
- `\mathbb{R}, \mathbb{N}, ...` (sets)
- `\mathcal{D}, \mathcal{R}` (domain/range notation)
- `C(\mathbb{R})`, `C(\mathbb{R},\mathbb{R})`, etc. (function spaces)

### DO wrap in \mathtt{...} (typography-discretionary)
- function-name tokens when you want the “name token” styled (e.g., `\mathtt{sinh}`, `\mathtt{cosh}`, `\mathtt{tanh}`)
- narrative labels/text tokens (“Sub.”, “Thus”, “From…”, etc.) when they appear as text.

### No style spread
Apply `\mathtt` deliberately; do not let it spread onto nearby convention-bound symbols unless explicitly requested.

### Narrative rows inside aligned
Do NOT wrap an entire narrative row in `\mathtt{...}` if it contains convention-bound symbols. Wrap only the text tokens; keep symbols outside. Example pattern:  
`& \mathtt{Thus } \mathcal{D}_{\mathtt{f}}=\mathbb{R} \mathtt{ and } \mathtt{f}\in C(\mathbb{R}).`

### Domain/range/continuity shorthand (example pattern)
- `\mathcal{D}_{\mathtt{f}}=\mathbb{R}\ \bigl(= (-\infty,\infty)\bigr)`
- `\mathcal{R}_{\mathtt{f}}=\mathbb{R}\ \bigl(= (-\infty,\infty)\bigr)`
- `\mathtt{f}\in C(\mathbb{R})`

### Hyperbolic rendering robustness
If `\sech`, `\csch`, etc. render unreliably, prefer:
- `\mathtt{sech}`, `\mathtt{csch}`, `\mathtt{coth}` (and inverses as `\mathtt{sech}^{-1}`, etc.), or
- `\operatorname{sech}` forms.  
Match diagram labels like “secht/cscht” via `\mathtt{sech}\,t`, `\mathtt{csch}\,t` as appropriate.

## Conditionals parsing (kaizen)

## Structural invariants from the exemplar

1. **Exactly one display block**  
    Everything is inside one `$$ ... $$` containing a single `\begin{aligned}...\end{aligned}`.
    
2. **One alignment column (one `&` per row)**  
    Every row contains exactly one `&`.
    
    - Section headers use `& ...` (blank left column).
        
    - Numbered assignment lines use `\mathtt{(n)} \quad & ...` (label before `&`).
        
3. **Sectioning is purely typographic, not semantic LaTeX environments**  
    Sections are bold text rows with trailing colon:
    
    - `& \textbf{Assignments:}\\[18pt]`
        
    - `& \textbf{Translating\ ...\ Forms:}\\[18pt]`
        
    - `& \textbf{Reasoning:}\\[18pt]`
        
4. **Vertical rhythm is controlled with fixed spacers**  
    Only these spacers appear: `\\[12pt]`, `\\[18pt]`, `\\[22pt]`  
    The exemplar uses:
    
    - `18pt` after section headers and before major moves,
        
    - `12pt` for tight intra-section line breaks,
        
    - `22pt` for section separation.
        

## Typography / token styling rules actually demonstrated

5. **Number labels are monospace**  
    `(1)`, `(2)`, `(3)` … are `\mathtt{(n)}`.
    
6. **Predicate letters and their argument tokens are monospace**  
    `\mathtt{G}(\mathtt{x})`, `\mathtt{M}(\mathtt{x})` — i.e., both the function/predicate symbol and the variable token.
    
7. **Do _not_ monospace convention-bound logical symbols**  
    `\forall`, `\to`, parentheses, `\bigl(\bigr)`, `\therefore`, `\Rightarrow` remain in normal math fonts.
    
8. **The “hat constant” is styled as `\hat{\mathtt{x}}`**  
    Not `\mathtt{\hat{x}}` and not `\hat{x}`. The hat sits on a monospace token.
    
9. **English narrative uses `\text{...}`; embedded math tokens still obey the monospace rules**  
    Example:  
    `& \text{``All geometers are mathematicians''}\;=\; ...`
    
10. **Backslash-space inside bold headers**  
    The long bold header uses escaped spaces:  
    `\textbf{Translating\ Propositional\ sentences\ into\ Propositional\ Forms:}`  
    (Not ordinary spaces.)
    

## Indentation / alignment tricks to replicate the handwritten layout

11. **“Given:” lines are narrative, with the step label _inside_ the line**  
    `& \text{Given:}\quad \mathtt{(3)}\quad ...`
    
12. **The derived line (4) is visually nested via `\phantom{...}` + `\Rightarrow`**  
    The key technique is:
    

& \phantom{\text{Given:}\quad \mathtt{(3)}\quad}\Rightarrow \mathtt{(4)}\quad ...

So the arrow line begins exactly under the content column of the “Given” line, without adding a second alignment column.

13. **The Modus Ponens / derivation sub-block is an `array` embedded as the RHS of step (6)**  
    The step label and the proof fragment are part of the same aligned row:
    

- `\mathtt{(6)}\quad` then a newline then `\begin{array}{c} ... \end{array}`
    
- The array is centered (`{c}`), with a horizontal rule `\hline` and a `\therefore\ ...` conclusion line.
    

14. **Spacing around `=` uses `\;` (not plain spaces)**  
    Example: `\text{...}\;=\;\forall ...`
    
15. **Quantifier line uses `\bigl(\bigr)` not brackets**  
    `\forall \mathtt{x}\,\bigl(\mathtt{G}(\mathtt{x})\to \mathtt{M}(\mathtt{x})\bigr)`  
    Note the thin space after the bound variable: `\,`.
