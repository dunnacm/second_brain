
$\mapsto$

$$
\begin{aligned}
& \textbf{Given\ atoms:}\\[18pt]
\mathtt{P}\;:=\;& \text{The sine function is not one-to-one}.\\[12pt]
\mathtt{Q}\;:=\;& \text{The square root function is one-to-one}.\\[12pt]
\mathtt{R}\;:=\;& \text{The absolute value function is not onto}.\\[22pt]
& \textbf{Translate\ the\ following\ propositional\ forms:}\\[18pt]
\mathtt{1.}\quad & \mathtt{P}\land \mathtt{Q}\lor \mathtt{R}\\[18pt]
& \mathtt{P}\land \mathtt{Q}\lor \mathtt{R}\;=\;\bigl(\mathtt{P}\land \mathtt{Q}\bigr)\lor \mathtt{R}\;=\;\text{Either the sine function is not one-to-one and}\\
& \text{the square root function is one-to-one, or the absolute value function is not onto}.\\[22pt]
\mathtt{2.}\quad & \mathtt{P}\land \bigl(\mathtt{Q}\lor \mathtt{R}\bigr)\\[18pt]
& \mathtt{P}\land \bigl(\mathtt{Q}\lor \mathtt{R}\bigr)\;=\;\text{The sine function is not one-to-one and either}\\
& \text{the square root function is one-to-one or the absolute value function is not onto}.
\end{aligned}
$$
